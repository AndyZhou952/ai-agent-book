## 题目原文

4. ★★ 消融实验中 “工具结果反馈” 的缺失会让 Agent 反复重试直到耗尽迭代预算。在生产环境中，除了工具结果缺失，还有哪些情况可能让 Agent 陷入这种循环？你会设计怎样的检测和终止机制？

## 我的答案（整理版）

除了工具结果缺失，以下情况也可能让 Agent 反复尝试：

- 工具一直返回同样的 error。
- 模型出现幻觉，调用不存在的工具。
- Context window compression 丢失中间状态。
- 任务在当前条件下本来就无法完成。

我会设置最大迭代次数等停止条件，并检测重复调用：不仅看工具名，还比较传入的参数是否相同或高度相似。

当重复调用或连续失败达到设定阈值后，停止继续重试，并升级到 human-in-the-loop，由人工接管。
