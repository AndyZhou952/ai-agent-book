## 题目原文

2. ★★★ ReAct 循环中，累计缓存读取量随轮数近似二次方增长。如何降低这种增长？

## 我的答案（整理版）

一个直接的办法是设置 token 用量或上下文长度阈值，达到阈值时再做压缩与 summarization。

压缩时保留之前的思考信息和关键节点，去掉不再需要的冗余细节，例如因格式问题产生的重复失败调用。大块中间结果可以外置，需要时再检索；也可以考虑用子 Agent 隔离，让部分中间过程不进入主 Agent 的上下文。

我不倾向于每轮都压缩：这可能损害性能，还会引入压缩调用和 recaching 的额外开销。相比之下，按阈值触发更合适。
