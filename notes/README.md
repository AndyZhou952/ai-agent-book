# 学习笔记

笔记默认在 `study-notes` 分支维护。每章使用两个直接阅读的文件：`answers.md` 汇总完整题目与整理版答案，`highlights.md` 汇总重点。所有整理说明统一放在 [editing-notes.md](editing-notes.md)。

## 存放方式

```text
notes/
  chapter-01/
    answers.md        本章全部题目与整理版答案
    highlights.md     本章全部重点摘记
    raw/              不修改内容的原始转写文字
    freeform/         独立存放的长段笔记、手写转写
    attachments/      原始图片、扫描件等附件
    anki/             按需制作的卡片及导出文件
  editing-notes.md     全部章节的整理说明、来源和补充记录
  cross-chapter/
  inbox/
  templates/
```

实际收到内容时才创建相应章节或目录。跨章笔记放 `cross-chapter/`；无法定位的输入先放 `inbox/`。

## 阅读文件的格式

- **思考题**：每章只维护一个 `answers.md`，以完整题目作为各题标题，下面直接写整理版答案，按题号排列。用户通常只提供答案，由 Agent 从本地 `book/chapterN.md` 找到完整题目；不要求用户重贴。后续补充直接合入同一章的文件，不再按题目或日期拆成多个整理版文件。
- **Highlights**：每章只维护一个 `highlights.md`，标题下面直接列重点。后续摘记合入同一文件，不按输入批次另建文件。
- 两种阅读文件都不加记录日期、题目来源、Git 版本、原稿链接、确认状态、整理说明、待确认清单或 Agent 补充，也不添加“无待确认项”等占位内容。
- 题目中可保留星级；答案中的段落、列表和必要的小标题按内容组织。参考答案启发若本就是用户答案的一部分，可自然保留其说明，不与 Agent 自行补充混为一谈。

## 原稿与整理记录

1. 先将收到的原始文字逐字保存到章节的 `raw/` 中，UTF-8 格式，不添加 Agent 说明，不清理口误、语气词、重复、中英混用或停顿标记。语音转文字只需保存原始转写，不要求音频。新一轮输入单独保存，不覆盖旧原稿。
2. 原稿文件使用 `YYYY-MM-DD-主题.raw.txt`；同日同主题加序号。整批输入可保存完整原稿和逐字摘出的各题原稿。日期默认采用 Asia/Taipei。
3. 整理时删除语气词、重复和无意义停顿，按上下文最可能的含义修正转写错误，保留观点、语气强弱、适用条件和技术术语，不逐项要求确认，也不补造未提供的理由或结论。
4. 所有处理解释写进唯一的 `notes/editing-notes.md`，按章节和题号组织；日期、正文路径与版本、原稿和附件链接也集中放在这里。必要的重大歧义、事实核对和 Agent 建议单独注明；没有实质内容时不新增占位记录。
5. 默认不先看参考答案。需要核对时，核对结果和来源只写入整理记录，不替换用户自己的答案。新补充合入阅读文件，同时在整理记录中关联新原稿。

## 自由笔记与手写材料

长段笔记独立存放，不强制转成 bullet points；需要整理时保留原稿，改写另存。手写笔记先保存实际可访问的原文件，再按需转写；无法辨认处可在转写中标明，可能的读法和解释写进整理记录。拿不到原件时在整理记录如实注明，不声称已归档。

## Anki 卡片

用户明确说“做成卡片”，或将要点标为 `#anki` 时，才把对应部分转为卡片；不把所有笔记自动制卡。

- 一张卡片只考一个可独立回答的知识点，题干包含必要上下文，答案简短、可检验。复杂思考题先保留完整答案，需要时再拆成适合复习的概念、条件或比较。
- 有歧义、未核实的事实不直接进入卡片；个人观点若用于复习，题干明确写“我的理解”，避免当成普遍结论。
- 在 `anki/<文件名前缀>.cards.md` 保存可读的问答、标签及相对来源链接；再按需导出同名前缀的 `.tsv`。Markdown 是维护稿，TSV 是导出稿，不做两个独立版本。
- 默认使用正反面问答。UTF-8 TSV 每条记录一行，三列依次为 `Front`、`Back`、`Tags`，以真实制表符分隔，不加入普通表头数据行。字段内换行用 `<br>`，正文中的 HTML 特殊字符先转义；标签用空格分隔。
- 导入时选择 Anki 的 Basic（或对应的基础问答）笔记类型，将三列映射到正面、背面和标签；使用 `<br>` 时启用字段内 HTML。卡片可带 `ai-agent-book chapter-01` 等标签，背面附来源说明，方便回看。
- 导出前检查重复问题。需要覆盖已有导出时从维护稿重新生成；修改已导入卡片的正面可能影响 Anki 的重复识别，重新导入前说明这一点。不自动连接或修改 Anki 牌组。

## 如何使用

可以直接说：“用 `$study-notes` 整理第二章，下面是我的重点和思考题答案：……”

- [答案模板](templates/answer.md)
- [重点模板](templates/highlights.md)
- [自由笔记模板](templates/freeform.md)
- [Skill 源码](../skills/study-notes/SKILL.md)

用户已授权整理后直接提交本流程相关文件并推送到 `origin/study-notes`，后续沿用，除非另行指定。提交前检查范围，不夹带无关改动，远端冲突时不强制推送。
